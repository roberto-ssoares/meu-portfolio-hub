# Meu Portfolio Hub



![](C:\Users\Roberto\AppData\Roaming\marktext\images\2026-04-21-14-59-09-image.png)



Portfólio estático em **HTML, CSS e Bootstrap** criado para apresentar meus projetos em **Ciência de Dados, Engenharia de Dados, Machine Learning e Analytics orientados a negócio**.

Este repositório funciona como a base pública da minha página de portfólio, reunindo projetos, resumo profissional, áreas de atuação e formas de contato.

---

## Visão Geral

O objetivo deste repositório é servir como uma vitrine técnica e estratégica da minha jornada em dados, com foco em:

- projetos aplicados
- storytelling analítico
- clareza de comunicação
- organização profissional para recrutadores e lideranças
- publicação web simples via GitHub Pages

A página principal apresenta:

- **Início**
- **Projetos em Destaque**
- **Tecnologias e Áreas de Atuação**
- **Sobre Mim**
- **Contato Profissional**

- `sobre.html` → resumo profissional e posicionamento
- `contato.html` → canais de contato
- `assets/img/` → imagens e elementos visuais do site

## Como Visualizar Localmente

Como este é um projeto estático, basta abrir o arquivo `index.html` no navegador.

### Opção simples

Clique duas vezes em:

index.html

### Opção recomendada

Use uma extensão de servidor local, como:

- **Live Server** no VS Code

Assim você consegue navegar melhor entre as páginas.

---

## Como Editar

### Alterar textos e estrutura

Edite os arquivos:

- `index.html`
- `projetos.html`
- `sobre.html`
- `contato.html`

### Alterar imagens

Adicione ou substitua arquivos em:

assets/img/

### Publicar mudanças

Depois de editar, rode:

git add .  
git commit -m "feat: atualiza portfolio hub"  
git push origin main

Se o GitHub Pages estiver configurado na branch principal, a publicação será atualizada automaticamente.
